# Godot 3D Scene Building

Use this skill to create, revise, or visually match a 3D scene through short native build-and-verify loops.

## Rules

- Treat the live scene, attached scripts, imported resources, ClassDB, diagnostics, and captures as authoritative. If editor and runtime differ, inspect both before classifying or deleting content.
- Prefer native nodes/resources and existing assets. Add code only for behavior native composition cannot express.
- Use one meter per unit unless the project establishes another scale. Prove one unfamiliar operation before repeating it; stop on failure.
- Use `class.search` or `class.introspect member_query=...` only for an unknown API or diagnosis. Both read the current engine's integrated Godot documentation. Do not repeat unchanged observations; the Harness caches native facts and supplies a compact state delta after writes.
- Captures verify framing, layout, and material likeness. They are not an exposure PID: diagnose geometry, sky, GI mode, physical-unit mode, camera attributes, and material response before changing exposure.
- Search `asset.catalog.search` by surface intent and choose ambientCG or Poly Haven explicitly, inspect one exact candidate, then acquire only a returned variant. Keep each material's maps from one asset family and use the returned physical dimensions to set scale. Never invent thin overlay CSG boards or emission fill to fake a missing pattern.

## Workflow

1. Inspect the current scene and files. Before placing an unfamiliar Mesh/PackedScene, read `resource.get_info.data.geometry`; after placement use `scene.instantiate.data.geometry`. These are authoritative meter-space AABBs, nested transforms, lowest point, topology and UV2 facts—never infer scale from a thumbnail. Lock room boundaries, openings, traversal, and reference camera/framing before materials or lighting. Plan on the ground plane in global coordinates: +X east, -Z north/forward.
2. Whitebox with `CSGBox3D`/`CSGCylinder3D` and coherent `objects.batch` edits. Keep shells sealed: walls/floor/ceiling must meet without gaps. Encode surface detail in materials/UVs — do not array thin boards against walls (they leak light). Keep collision simpler than visible geometry. Each successful batch returns affected nodes with global transforms and complete subtree geometry. Math properties accept ordered component arrays or named component objects such as `{ "x": 1, "y": 2, "z": 3 }`. Put structural geometry and fixed architectural finishes under dedicated roots. Give every repeated finish family one `Node3D` parent at its shared world datum; split runs at openings. Pass all roots together in one `scene.validate_structure`. Declare exact contacts with `max_gap`; use `contains`, `align`, and `no_overlap` for coverage, shared datums, and opening clearance. Omit `placement_roots` and `placements` until physical prop/fixture support must be verified, then supply both together. For reference-image work, also submit a non-empty `reference_layout` bound to the exact attachment: use `extent`, `anchor_distance`, and `axis_alignment` constraints in meters for the dimensions, wall anchoring, and orientation the image requires. The engine measures live Mesh/CSG facts and returns required evidence views.
3. Capture every `required_views` entry returned by layout validation. `target=orthographic` accepts axis/direction, exact focus_paths, and an explicit section_position so enclosed rooms can be inspected without mutating or hiding ceilings. `top_down` is its overhead preset. Then verify framing with `target=camera`. Only one Camera3D may be current. Reuse an unchanged content hash at the same revision.
4. For CSG, use `StandardMaterial3D` world-space triplanar mapping. Determine a real `meters_per_repeat` from official physical dimensions; when unknown, choose and state it explicitly, then convert it to `uv1_scale`. Disable Height while triplanar mapping is active because Godot does not support both together. Acquire one coherent PBR set from the selected catalog; search alone never downloads the full asset.
5. Reuse a loadable material entrypoint returned by `asset.import_to_project`; when a catalog asset is a texture set, create one `StandardMaterial3D` from that single imported map family. Verify scale, Albedo, NormalGL, Roughness, AO/ORM, metallic/transparency, and color space. Never combine maps from different asset families. Use `ShaderMaterial` only when `StandardMaterial3D` cannot express the surface, and never use material emission as room fill light.
6. During layout iteration use Forward+ SDFGI with a physically motivated dominant light and environment. Read `rendering/lights_and_shadows/use_physical_light_units`: when enabled, use lux/lumens with `CameraAttributesPhysical`; otherwise use Godot's non-physical workflow. For fully enclosed interiors disable SDFGI sky reading. Fix GI causes with sealed geometry, sky, light placement, and camera exposure, not arbitrary fill lights.
7. For final static interiors, call `scene.bake_csg` with exact CSG root paths, pass only its returned meshes that still lack UV2 to `mesh.unwrap_uv2`, then call `lightmap.bake` with the exact `LightmapGI` path. Static imported models use Godot's native Static Lightmaps import mode and `.unwrap_cache`; verify the import result's real `triangle_count` and `uv2_complete` instead of unwrapping those models again. If a generated model exceeds its requested topology budget, create a remeshed version before placement. Never use selection-dependent editor actions for this pipeline. Each tool returns a versioned artifact, and upstream geometry or mesh-data changes invalidate downstream evidence. After a valid LightmapGI bake, disable SDFGI so one final GI system is authoritative. Add `ReflectionProbe` only where reflections need it. Height may be enabled only on a final mesh with correct UVs and calibrated scale.
8. For each requested prop, honor an explicit user source first. Otherwise search the current project, then `asset.list_local`, then ambientCG or Poly Haven with `asset.catalog.search kind=3d`; inspect, acquire, import and instantiate the best exact candidate. Call Meshy only when authorized and no reusable asset fits. One isolated prop per generation job; omit attachments for Text-to-3D and pass only explicit isolated-object images for Image-to-3D. Continue independent work while jobs run, then call `job.wait` once when only their results remain. After placement, validate every prop/fixture with exactly one real support relation and repeat the same reference_layout contract. Then verify dimensions, orientation, materials, collision, camera and runtime. Judge lighting from images and measurements, never a Harness-invented aesthetic threshold.
